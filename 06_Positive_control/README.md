# 06_Positive_control

Validation of the gene classification pipeline using publicly available H3K27me3 ChIP‑seq data from mouse ES cells and G1ME cells (Young et al., 2011; GEO: GSE27970).

## Overview

To confirm that our repaired and adapted classification pipeline produces results consistent with the original publication, we downloaded the raw BAM files from GSE27970 and processed them through the same SICER2‑based workflow used for the embryo data.

Key challenges addressed:
- **Old BAM format**: Files were generated by Bowtie 0.11.3 and had malformed `@PG` headers
- **Legacy chromosome names**: After initial processing, SICER2 failed because chromosomes were named as `10.1-129993255` instead of standard UCSC `chr10`. This was discovered during SICER2 peak calling and required an additional renaming step.
- **Fragment size**: The original library used 200 bp fragments, requiring `--fragment_size=100` in SICER2

## Data source

| Sample | GEO Accession | Description |
|--------|--------------|-------------|
| ES_H3K27me3 | GSM691591 | Mouse ES cells, H3K27me3 ChIP |
| ES_WCE | GSM691593 | Mouse ES cells, whole cell extract (Input) |
| G1ME_H3K27me3 | GSM691594 | Mouse G1ME cells, H3K27me3 ChIP |
| G1ME_WCE | GSM691596 | Mouse G1ME cells, whole cell extract (Input) |

## Workflow

1.  **Fix BAM headers** (`fix_bam_header.sh`)  
    → 修复旧版 Bowtie BAM 文件的 `@PG` 头格式错误。

2.  **Standard BAM processing** (`process_bam_standard.sh`)  
    → 去除黑名单区域和 PCR 重复。

3.  **Rename chromosomes** (`rename_chromosomes.sh`)  
    → 将染色体命名从旧格式（`10.1-129993255`）转换为标准UCSC格式（`chr10`）。

4.  **SICER2 peak calling** (`run_sicer2_ES_G1ME.sh`)  
    → 使用 SICER2 进行富集峰检测（`--fragment_size=100`）。

5.  **Gene classification** (`run_classification.sh`)  
    → 调用 `ClassifyGenes.R` 和 `functions.R` 进行基因分类。

6.  **Generate validation plots** (`plot_validation_profiles.sh`)  
    → 使用 deepTools 绘制 TSS/TES 信号分布图和热图。


## Directory contents

| File | Description |
|------|-------------|
| `fix_bam_header.sh` | Repair malformed `@PG` header lines in legacy Bowtie BAM files using Picard SortSam |
| `process_bam_standard.sh` | Standard BAM processing: blacklist removal + PCR duplicate removal |
| `rename_chromosomes.sh` | Convert chromosome names from legacy format (`10.1-129993255`) to UCSC format (`chr10`). This step was added after discovering that SICER2 could not parse the original chromosome names |
| `run_sicer2_ES_G1ME.sh` | Run SICER2 peak calling on repaired BAM files |
| `ClassifyGenes.R` | Classification script (USER PARAMETERS pre‑set for ES cells; uses `functions.R` from `05_Gene_classification/`) |
| `functions.R` | Helper functions required by `ClassifyGenes.R` (copied from `05_Gene_classification/`) |
| `run_classification.sh` | Wrapper to run `ClassifyGenes.R` for both ES and G1ME cells |
| `plot_validation_profiles.sh` | Generate TSS and TES profile plots and heatmaps using deepTools |

## Usage

### 1. Download data

Download the BAM files from GEO (GSE27970):

- GSM691591 (ES H3K27me3)
- GSM691593 (ES WCE)
- GSM691594 (G1ME H3K27me3)
- GSM691596 (G1ME WCE)

### 2. Fix BAM headers

```bash
bash fix_bam_header.sh
```

### 3. Standard BAM processing

```bash
bash process_bam_standard.sh GSM691591_ES.H3K27 /path/to/mm10.blacklist.bed
bash process_bam_standard.sh GSM691593_ES.WCE   /path/to/mm10.blacklist.bed
bash process_bam_standard.sh GSM691594_G1ME.H3K27 /path/to/mm10.blacklist.bed
bash process_bam_standard.sh GSM691596_G1ME.WCE   /path/to/mm10.blacklist.bed
```

### 4. Rename chromosomes

**Note**: This step was added after discovering that SICER2 could not recognise the legacy chromosome names. It must be run before peak calling.

```bash
bash rename_chromosomes.sh
```

### 5. Run peak calling

```bash
bash run_sicer2_ES_G1ME.sh
```

### 6. Run classification

Before running, edit the `USER PARAMETERS` block in `ClassifyGenes.R` to point to your BAM files, SICER2 island file, and TxDb database. All paths are set to `./` by default.

```bash
bash run_classification.sh
```

**Output**: `ES_Gene_classification.txt`, `G1ME_Gene_classification.txt`

### 7. Generate validation plots

```bash
bash plot_validation_profiles.sh
```

Generates TSS profile, TES profile, and heatmap PDFs for both ES and G1ME samples.

## Key parameters

| Parameter | Value | Reason |
|-----------|-------|--------|
| `--fragment_size` | 100 | Original library size‑selected for 200 bp fragments |
| Genome | mm9 | The original publication used NCBI37/mm9 |
| Gap size | 600 | Same as embryo data for consistency |
| FDR | 0.01 | Standard SICER2 threshold |
| TSS/TES window | 30000 bp | Extended window for clear visualisation |

## Validation result

Our pipeline successfully reproduced the three H3K27me3 distribution patterns (Promoter, TSS, Broad) in both ES cells and G1ME cells, consistent with Young et al. (2011, Figure 2).

This confirms that the repaired and adapted classification method is reliable for application to *in vivo* early embryo data across multiple species.

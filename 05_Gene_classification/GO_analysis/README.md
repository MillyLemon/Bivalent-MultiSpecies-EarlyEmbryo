# GO_analysis (Gene Classification)

Gene Ontology biological process enrichment analysis for H3K27me3‑classified genes. This sub‑module performs GO enrichment separately for **Promoter+TSS** (narrow peak) and **Broad** (broad domain) gene sets, based on the gene classification results from `ClassifyGenes.R`.

This analysis corresponds to Thesis Figure 3‑15 and is distinct from the GO analysis of three peak categories (bivalent / K4‑only / K27‑only) in `04_Bivalent_analysis/GO_analysis/`.

## Directory contents

| File | Description |
|------|-------------|
| `add_entrez.R` | Batch conversion of Ensembl gene IDs to Entrez IDs using a GENCODE reference mapping table. Outputs `Gene_classification.entrez.txt` in each sample directory. |
| `run_classification_GO.R` | GO‑BP enrichment for Promoter+TSS and Broad gene sets using `clusterProfiler`. Generates dotplots and CSV result files. |

## Workflow

1. **Add Entrez IDs** (`add_entrez.R`)  
   读取 `Gene_classification.txt` → 提取 Ensembl ID → 去除版本号 → 在参考映射表中查找对应的 Entrez ID → 输出 `Gene_classification.entrez.txt`  
   未匹配的基因保留为 `NA`，后续分析中用 `na.omit()` 过滤。

2. **Run GO enrichment** (`run_classification_GO.R`)  
   读取 `Gene_classification.entrez.txt` → 分别提取 Promoter+TSS 基因和 Broad 基因的 Entrez ID → 使用 `clusterProfiler::enrichGO` 进行 BP 富集 → 生成气泡图和 CSV 结果表  
   **输出**: `GO_analysis_by_classification_2/results/*.csv`, `GO_analysis_by_classification_2/plots/*.pdf`

## Input

| Data | Source | Description |

## Key analysis decisions

### Why Promoter+TSS combined?

Promoter and TSS genes both exhibit narrow H3K27me3 peaks. They were combined to increase statistical power for GO enrichment analysis, as individual gene sets were often too small (< 50 genes) to yield significant enrichment results.

### Entrez ID conversion

Ensembl gene IDs were converted to Entrez IDs using a reference mapping table derived from GENCODE vM23. Conversion rates varied by species:
- Mouse and human: > 70%
- Rat, bovine, porcine: ~ 47% (due to less complete annotation in public databases)

Unmatched genes were excluded from enrichment analysis using `na.omit()`.

### Statistical thresholds

GO enrichment was performed with:
- **Ontology**: Biological Process (BP)
- **Multiple testing correction**: Benjamini‑Hochberg (BH)
- **Significance threshold**: adjusted *P* ≤ 0.05

## Notes

- **Final figure**: The GO dotplots in Thesis Figure 3‑15 were generated by this script and further refined in Adobe Illustrator for publication.
- **Cross‑species application**: The same scripts were applied to all five species. The `OrgDb` parameter in `run_classification_GO.R` should be changed accordingly (`org.Mm.eg.db`, `org.Hs.eg.db`, `org.Rn.eg.db`, `org.Bt.eg.db`, `org.Ss.eg.db`).
- The `sample.name` file should list one sample directory name per line, matching the subdirectories containing `Gene_classification.txt`.

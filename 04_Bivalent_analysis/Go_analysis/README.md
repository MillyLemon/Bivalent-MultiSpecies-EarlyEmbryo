# GO_analysis (Bivalent)

Gene Ontology biological process enrichment analysis for three histone modification categories: **H3K4me3‑only**, **H3K27me3‑only**, and **Bivalent**. This analysis corresponds to Thesis Figure 3‑12 and Appendix Figures A16–A19.

## Directory contents

| File | Description |
|------|-------------|
| `three_category_GO.R` | GO‑BP enrichment for three peak categories (K4‑only, K27‑only, bivalent). Adaptable to any species by changing the `OrgDb` parameter. |

## Input

Input files are Ensembl gene ID lists (one ID per line, version numbers removed), generated by extracting Ensembl IDs from filtered `.annotate` files. These files are **shared** with the expression analysis module (Figure 3‑11).

**Example format** (`2_cell_K4only_ensembl.txt`):

```
ENSMUSG00000000001
ENSMUSG00000000028
ENSMUSG00000000037
```

## Usage

1. **Edit parameters** in `three_category_GO.R`:
   - `SPECIES`: Species name for plot titles
   - `STAGE`: Developmental stage name
   - `ORG_DB`: Species annotation package (`org.Mm.eg.db`, `org.Hs.eg.db`, etc.)
   - `KEY_TYPE`: Gene ID type (usually `"ENSEMBL"`)
   - `FILE_K4`, `FILE_K27`, `FILE_BIV`: Paths to the three gene list files

2. **Run the script**:
   ```r
   source("three_category_GO.R")
   ```

## Output

| Output | Description |
|--------|-------------|
| `GO_<stage>_<species>.pdf` | Combined GO dotplot with three panels (K4‑only, K27‑only, bivalent) |

## Notes

- This analysis uses **gene‑level Ensembl IDs**, identical to those used in the expression analysis (Figure 3‑11). The gene lists were generated once and reused across both analyses.
- The GO enrichment results for mouse 2‑cell and human 8‑cell stages are shown in Thesis Figure 3‑12. Complete results for all stages are in Appendix Figures A16–A19.
- For GO enrichment of **Promoter+TSS vs Broad** gene classes (based on gene classification results), see `05_Gene_classification/GO_analysis/`.

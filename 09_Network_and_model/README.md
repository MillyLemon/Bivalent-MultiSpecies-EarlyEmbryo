# 09_Network_and_model

Construction of the integrated **transcription factor – target gene – biological pathway** regulatory network and the speculative regulatory model for H3K27me3 narrow peak establishment.

## Overview

This module performs the final integrative analysis linking motif predictions to functional annotations. The workflow consists of three computational steps followed by manual figure generation:

1. **Extract target genes** from HOMER motif analysis output
2. **GO enrichment analysis** on target gene sets
3. **Build network tables** for Cytoscape import
4. **Manual figure generation**

**Final figures were generated as follows**:
- **Figure 3‑17** (integrated regulatory network): generated manually using **Cytoscape** from the edge and node tables produced by `step3_build_network_table.R`.
- **Figure 4‑1** (speculative regulatory model): drawn manually in **PowerPoint**, illustrating the proposed mechanism of H3K27me3 narrow peak establishment. This figure is a schematic diagram based on literature integration and motif co‑localisation results from this study; it is not generated by code.

## Directory contents

| File | Description |
|------|-------------|
| `step1_extract_motif_genes.py` | Extract unique target gene symbols from HOMER `annotatePeaks.pl` output files |
| `step2_GO_and_network.R` | GO enrichment analysis on target genes; generate preliminary network edge file |

## Workflow

1. **Extract target genes** (`step1_extract_motif_genes.py`)  
   → 从 HOMER `annotatePeaks.pl` 输出文件中提取每个转录因子的唯一靶基因列表。  
   → **输出**: `NR4A2_gene_list.txt`, `PRDM1_gene_list.txt`, `ZBTB18_gene_list.txt`, `ZNF135_gene_list.txt`

2. **GO enrichment & preliminary network** (`step2_GO_and_network.R`)  
   → 使用 `clusterProfiler` 对靶基因进行 GO 生物学过程富集分析，生成每个 TF 的 GO 气泡图。  
   → 构建初步网络边文件，连接 TF 与其靶基因及显著富集的 GO 通路。  
   → **输出**: `TF_GO_enrichment_all.csv`, `network_edges.csv`, `TF_GO_dotplot.pdf`

3. **Curate network tables** (`step3_build_network_table.R`)  
   → 手动整理最终的 TF–靶基因–GO 通路网络结构，涵盖 ICM 期（NR4A2, ZBTB18, PRDM1）和 8 细胞期（ZNF135）。  
   → 添加 IGV 共定位验证的连接（NR4A2–Otx2, PRDM1–Neurod1）。  
   → **输出**: `network_edges_all.txt`, `network_nodes_all.txt`

4. **Visualise network in Cytoscape** (manual, for Figure 3‑17)  
   → 将 `network_edges_all.txt` 和 `network_nodes_all.txt` 导入 Cytoscape。  
   → 手动调整布局、节点颜色和边样式，生成论文图 3-17（整合调控网络）。

5. **Draw mechanistic model in PowerPoint** (manual, for Figure 4‑1)  
   → 在 PowerPoint 中手动绘制推测性调控模型示意图。  
   → 该图整合了文献证据和本研究的 motif 共定位结果，展示 H3K27me3 窄峰建立的推测性调控机制。

## Cytoscape import instructions

### File formats

**`network_edges_all.txt`** (tab-separated):

| Source | Target | Evidence | Stage | Type |
|--------|--------|----------|-------|------|
| NR4A2 | Sox1 | HOMER motif scan | ICM | Motif |

| Node | Type | Function | Stage |
|------|------|----------|-------|
| NR4A2 | TF |  | ICM |
| Sox1 | Target | neural progenitor / forebrain development | ICM |
| central nervous system neuron development | GO_BP | GO Biological Process | NA |

### Import steps

1. Open Cytoscape
2. **File → Import → Network from File** → select `network_edges_all.txt`
3. **File → Import → Table from File** → select `network_nodes_all.txt` → import as Node Table
4. Style nodes by `Type` column (TF = orange triangle, Target = blue circle, GO_BP = light yellow hexagon)
5. Style edges by `Evidence` column (Motif = grey dashed line, IGV = red solid line)

## Key analysis decisions

### Why manual curation?

The final network was manually curated rather than automatically generated to:
- Focus on biologically relevant connections
- Include only genes with clear developmental functions
- Highlight IGV‑validated co‑localisation events (NR4A2–Otx2, PRDM1–Neurod1)
- Maintain visual clarity for publication

### Why Cytoscape?

Cytoscape was chosen over R (igraph/ggraph) for final network figure generation (Figure 3‑17) because it provides better control over node placement, edge routing, and visual styling.

### Why PowerPoint?

The mechanistic model (Figure 4‑1) was drawn manually in PowerPoint as a schematic diagram. This approach was chosen for its flexibility in creating publication‑quality illustrations that combine conceptual elements from multiple literature sources.

## Key findings

### ICM stage (NR4A2 + ZBTB18 + PRDM1)

- **NR4A2** and **ZBTB18** co‑regulate central nervous system developmental genes
- Target genes significantly enriched in "central nervous system neuron development" (GO:0021954)
- **PRDM1** targets enriched in organ morphogenesis and haematopoietic development

### 8‑cell stage (ZNF135)

- **ZNF135** primarily targets genes involved in pattern specification (GO:0007389) and kidney development (GO:0001822)

### Mechanistic model (Thesis Figure 4‑1, drawn in PowerPoint)

The speculative regulatory model (Figure 4‑1) was drawn manually in PowerPoint. It illustrates the proposed mechanism of H3K27me3 narrow peak establishment, integrating literature evidence from:
- Zeng et al. (2025) on EZHIP restricting PRC2 activity *in vivo*
- Glancy et al. (2024) on active chromatin environments excluding PRC2
- Motif co‑localisation results from this study (Figure 3‑16)

**Panel A (Broad pattern)**: PRC2 broadly deposits H3K27me3 across the gene body → stable transcriptional repression.

**Panel B (Promoter/TSS narrow‑peak pattern)**: Transcription factors (e.g., NR4A2, PRDM1) bind at promoter/TSS regions and sterically restrict PRC2 propagation into the gene body → H3K27me3 is constrained to a narrow zone → the gene remains poised or active.

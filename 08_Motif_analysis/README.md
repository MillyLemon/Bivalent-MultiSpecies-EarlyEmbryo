# 08_Motif_analysis
Transcription factor binding motif enrichment analysis using **HOMER** (`findMotifsGenome.pl`).
## Overview
Motif enrichment analysis was performed separately for **Promoter+TSS** (narrow peak) and **Broad** (broad domain) gene sets. The analysis identifies transcription factor binding motifs that are significantly over‑represented in the regulatory regions of each gene class.

## Directory contents

| File | Description |
|------|-------------|
| `run_motif_analysis.sh` | HOMER motif analysis master script: extracts peak coordinates from `.annotate` files based on gene lists and runs `findMotifsGenome.pl` |

## Usage

### 1. Prepare input files

Before running the script, ensure the following are available:

- **HOMER genome databases** for all species (see `07_Multi_species/install_homer_genomes.sh`)
- **`.annotate` files** generated by HOMER `annotatePeaks.pl` (see `04_Bivalent_analysis/`)
- **Gene classification BED files** (`broad_genes.bed`, `promoter_genes.bed`, `tss_genes.bed`) in per‑sample subdirectories
- **Sample list file** (`sample.name`) with one sample name per line

Combine Promoter and TSS gene lists before running:

```bash
for dir in */; do
    cat "${dir}promoter_genes.bed" "${dir}tss_genes.bed" > "${dir}promoter_tss_genes.bed"
    echo "Merged: $dir"
done
```

### 2. Edit script parameters

Before running, edit the following variables in `run_motif_analysis.sh`:

| Variable | Description | Example |
|----------|-------------|---------|
| `ANNOTATE_DIR` | Directory containing `.annotate` files | `/path/to/sicer2/` |
| `GENOME` | Reference genome for HOMER | `mm10`, `hg38`, `rn6`, `bosTau9`, `susScr11` |
| `HOMER_TOOL_PATH` | Path to `findMotifsGenome.pl` | `/path/to/homer/bin/findMotifsGenome.pl` |

### 3. Run analysis

```bash
bash run_motif_analysis.sh
```

**Parameters passed to HOMER**:

| Parameter | Value | Description |
|-----------|-------|-------------|
| `-size` | 200 | Analysis window size (bp) |
| `-mask` | on | Mask repetitive sequences |
| `-p` | 4 | Number of threads per job |

### 4. Output

For each sample and each gene list type (`broad`, `promoter_tss`), the script generates:

| Output | Location | Description |
|--------|----------|-------------|
| `knownResults.txt` | `motif_promoter_tss/` or `motif_broad/` | Full list of known motif enrichment results |
| `homerResults.html` | `motif_promoter_tss/` or `motif_broad/` | *De novo* motif discovery results |
| `Analysis_Summary.txt` | Main output directory | Summary report with processing status for all samples |

**Note on downstream processing**: The significant motifs presented in the thesis were manually screened from the `knownResults.txt` files and formatted into publication‑ready tables using external software. No automated formatting script is included in this repository.

## Workflow logic

The script implements the following logic (as determined during project discussions):

1.  **Extract gene IDs** from the gene classification BED files (column 4, Ensembl IDs with version numbers removed)
2.  **Match gene IDs** to the `.annotate` file (column 15, Nearest Ensembl), excluding `Intergenic` annotations
3.  **Extract peak coordinates** directly from the `.annotate` file, ensuring the analysed DNA intervals correspond exactly to the annotated peaks
4.  **Generate BED files** containing the peak coordinates
5.  **Run HOMER** on the BED files

This approach ensures motif analysis is performed on the **regulatory regions (peaks)** associated with each gene class, rather than on the gene body sequences themselves.

## Key analysis decisions

### Why Promoter+TSS combined?

Promoter and TSS genes both exhibit narrow H3K27me3 peaks. They were combined to increase statistical power for motif detection.

### Threshold selection

Motifs were filtered using stringent thresholds:

| Criterion | Threshold | Rationale |
|-----------|-----------|-----------|
| P‑value | < 1 × 10⁻¹² | Minimise false positives from multiple testing |
| Fold Enrichment | > 9 | Focus on the most biologically relevant motifs |

At these thresholds, four transcription factors (ZNF135, ZBTB18, NR4A2, PRDM1) were identified in Promoter+TSS genes. Broad genes showed enrichment for SOX, GATA, and other lineage‑specifying factors (complete list in thesis Appendix Table B3).

### Why HOMER?

HOMER was chosen because it provides a curated database of known transcription factor binding motifs, supports all five species used in this study, and allows repeat masking.

## Key findings

- **Promoter+TSS genes**: Enriched for ZNF135 (8‑cell stage), ZBTB18, NR4A2, and PRDM1 (ICM stage) binding motifs
- **Broad genes**: Enriched for SOX, GATA, and other lineage‑specifying transcription factor motifs
- **Stage‑specific regulation**: ZNF135 was specific to the 8‑cell stage, while ZBTB18, NR4A2, and PRDM1 were enriched at the ICM stage
